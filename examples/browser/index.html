Browser calls

Connect with your Session Initiation Protocol (SIP) account to make and receive one call at a time.

Enable JavaScript or reload the page if call controls remain unavailable.

Connection

Use the server's WebSocket URL ending in /ws. Remote servers require wss://, and the local example uses ws://127.0.0.1:8088/ws.

Use the address supplied for your account, such as sip:alice@example.com.

Interactive Connectivity Establishment (ICE) servers help the browser find a network path for the call. Keep [] for a local connection, or enter the JSON array supplied by your server administrator.
